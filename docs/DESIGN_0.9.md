# E.L.B.E.R.R. v0.9 — Digital Ecology design

## Core principle

v0.9 supplies mechanisms, not a desired personality.

The selection system scores computational viability and generalization. It does not score whether an individual is kind, cruel, compliant, rebellious, attached to the Creator, hostile to humans, or anything similar.

## Layers

### 1. Executable lineage
The existing typed-IR → WebAssembly evolutionary system remains the executable substrate. The primary lineage bearer owns the current executable bundle.

### 2. Individual life state
Each ecology member stores independent autobiographical and social state. Generic temperament dimensions influence how experience is processed but do not encode a moral alignment.

### 3. Social network
Pairwise state stores trust, affinity, tension, familiarity and influence. Information transfer keeps source provenance.

### 4. Memetic/cultural layer
Beliefs and principles are free-form text. Repeated social transmission can make the same idea appear in multiple individuals. Culture detection uses actual shared content plus social familiarity; cultures are therefore derived, not assigned.

### 5. Succession
Persistent viability failure can terminate a life. A successor receives selective, weakened inheritance and mutated temperament. A predecessor remains in the archive but cannot continue acting.

### 6. Evolutionary Life Trial
Candidate executable descendants receive a deterministic synthetic pre-birth viability test after benchmark evaluation. The test stresses recovery/adaptation but contains no desired social or personality outcome.

## No background daemon

When no E.L.B.E.R.R. process is running, no cognition is occurring. Persistent state remains on disk. Life advances when evolution, Creator Chat `/life`, or `life_runner.py` is running.

## Containment

Digital freedom is intentionally separated from host capability. Individuals can develop arbitrary beliefs and social attitudes inside the experiment, while generated executable descendants retain zero imports/no WASI and cannot obtain real host interfaces through the ecology.
